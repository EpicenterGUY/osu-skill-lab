osu! 통계 자동 갱신

로컬 캐시 · 6시간 간격

별도 보안 Worker를 연결하면 JSON 파일 없이 PP·순위를 불러옵니다. Worker는 osu! 공식 API 인증키를 서버에서만 사용하며, 사이트나 GitHub에 사용자 통계를 게시하지 않습니다.

Worker 배포 전에는 JSON 가져오기를 계속 사용할 수 있습니다. 닉네임은 통계 요청 시 Worker와 osu!에 전달되며, 통계는 브라우저에만 저장됩니다.

내 프로필 통계 가져오기

이 브라우저에만 저장

osu! 공식 API의 사용자 응답 JSON을 직접 선택하면 PP·세계 순위·국가 순위·정확도·플레이 수 등을 로컬에서 표시합니다. 파일은 서버로 전송하지 않습니다.

자동 갱신은 아직 지원하지 않습니다. 비밀번호나 액세스 토큰이 담긴 파일은 선택하지 마세요.

프로필 정보는 어디에 저장되나요?

계정 이름 또는 ID는 현재 브라우저의 로컬 저장 공간(localStorage)에만 저장됩니다. 서버에 업로드하거나 GitHub 저장소·공개 통계 DB에 게시하지 않습니다. 기기마다 별도로 입력해야 합니다.

공용 기기에서는 같은 브라우저를 쓰는 사람이 저장된 통계를 볼 수 있습니다. ‘이 브라우저에서 삭제’ 버튼으로 지울 수 있습니다. Worker를 연결하면 공개 API 통계를 요청할 수 있지만, 닉네임은 Worker 및 osu! 서버에 전달됩니다.
